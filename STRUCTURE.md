# Gamevers — Frontend

Technologie: Vue 3, Vite, Vue Router, Pinia, Axios, Tailwind CSS.

## Struktura src/

- components/ — komponenty wielokrotnego użytku
- views/ — widoki aplikacji
- router/ — konfiguracja tras
- stores/ — stan aplikacji
- services/ — komunikacja z REST API
- assets/ — grafiki i style
- composables/ — logika współdzielona

## Zasady

- Composition API i script setup
- Interfejs w języku polskim
- Responsywność zgodna z Figmą
- Komunikacja z backendem przez REST API
- Brak logiki backendowej w komponentach Vue

## Status

Struktura planowana. Projekt Vue zostanie
wygenerowany na komputerze za pomocą Vite.

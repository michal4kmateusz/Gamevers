
Create a complete, professional, high-fidelity UI/UX mockup for a modern gaming discovery platform called GAMEVERS.
PROJECT OVERVIEW
Gamevers is a modern gaming portal where users can discover video games, explore detailed game information, search and filter a game catalog, rate and review games, and manage their personal gaming library.
The project will be developed using Vue 3, Laravel and MySQL.
Create a realistic, visually impressive, modern gaming platform inspired by the visual quality of Opera GX, Steam, Epic Games Store and modern gaming dashboards, but with a unique and original identity.
This is NOT an online game store. Do not add shopping carts, payments, game purchases or game launchers.
The entire user interface must be in Polish.
